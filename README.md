# Cult of the Dead Bunnies

A small, static ASCII-inspired site built around the supplied pixel-art logo. It uses plain HTML, CSS, and JavaScript; there is no build step or backend.

## Run locally

From this directory:

```sh
python3 -m http.server 8000 -d dist
```

Open `http://localhost:8000`. The terminal is a local, playful command prompt. It does not execute system commands or send input anywhere.

The supplied `Group Logo - Inspiration.jpg` is retained at the project root, with a copy in `dist/assets/` for the site.
